PROJECT : 
Smart Crop Selector 

FULL DESCRIPTION(prblm statement) :
Selecting the right crop depends on several factors such as soil, climate, location, historical yield, and market conditions.
Build a web application that uses agricultural data to recommend suitable crops for a selected location or farm. 
The system should rank possible crops, display expected performance, compare alternatives, 
and provide analytics explaining the factors behind each recommendation.
